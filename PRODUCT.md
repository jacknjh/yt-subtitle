# Product

## Register

product

## Users and purpose

Premiere editors generating editable animated subtitle graphics from an existing transcript. The approved workflow and editing rules are in docs/plans/2026-11-03-subtitle-graphics-design.md.

## Interface direction

The user requested an extension that feels native to Premiere. Use host controls for the initial diagnostic panel. Production branding has not been specified; the prototype establishes no separate visual identity.

## Design principles

- Keep the editor in Premiere and preserve direct timeline edits.
- Act on the active sequence and explicitly selected destination graphics.
- Preserve word timing independently from phrase grouping and style.
- Distinguish diagnostics from verified functionality.

## Accessibility

Use labeled controls, keyboard-operable host buttons, and text status messages. No decorative motion is needed for diagnostics. Production accessibility requirements remain to be specified.
