Using Subtitle Generator


Get started

  1. Generate a transcript in Premiere. The active timeline’s words load automatically; use Refresh after corrections.
  2. Set the phrase length and line count in Generate. Choose appearance and preview a phrase in Style.
  3. Click Generate subtitles. Editable word graphics are added to an empty top video track in the current sequence.
  4. Adjust timing directly on the timeline. Use Edit to correct phrases or match selected graphics to a parent.


Each project and timeline remembers its own transcript snapshot and settings. Automatic transcripts refresh again before generation.


Style, alignment and preview


Preview
Play or scrub a phrase while adjusting style. The preview stays visible as settings scroll. Premiere is the final reference for spacing and rendering.


Alignment and Default
Left, Center and Right anchor the visible phrase at the horizontal position. Turn on Default to center the completed phrase: Left reveals from its fixed left edge; Right grows leftward in spoken order; Center keeps recentering.


Two lines
Choose Up to 2 lines in Generate. The complete phrase determines a balanced word-boundary break before reveal. The character limit covers both lines. The bottom line uses the vertical position; the other sits above it.


Fonts, colors and values
Search fonts, then choose a face. Click a swatch or type a six-digit hex color. Drag numeric values, or click to type and use arrow keys. Shift gives finer drags; Escape cancels a drag. Rerun the installer to refresh newly installed fonts.


Reset all style
Restores Times New Roman, plain word reveal, centered alignment and a 50% horizontal / 90% vertical anchor. Phrase grouping stays unchanged. Saved settings are retained until you change or reset them.


Undo and Redo
Restore panel style and grouping with Ctrl+Z, Ctrl+Shift+Z or Ctrl+Y. Each drag is one step. Text fields retain normal typing undo. Each timeline keeps its own history while the panel is open. Timeline edits use Premiere’s undo.




Pause, resume or discard a run


Pause and Resume
Pause finishes the current batch. Switching timelines also pauses generation. Return to the original timeline and click Resume; its original word plan and style are kept. Keep generated subtitle positions unchanged until the run finishes. Other tracks can be edited freely.


Discard run
Forgets progress and leaves completed graphics on the timeline. Remove those graphics before generating again there.


One unfinished run is kept while this panel remains open. Closing the panel or Premiere loses resumable progress.


Edit graphics on the timeline


Set parent and Sync selected
Place the playhead over a generated graphic and set it as parent. Select destination graphics, then sync. Sync reads the parent’s latest appearance while preserving destination text and timing. Click Sync again after later parent edits; it is not a continuous link. Added effects such as S_Shake, Motion, Transform and Drop Shadow are preserved on destinations but are not copied. Keyframed template style controls block Sync.


Read and Update phrase
Select a generated graphic and read its phrase. Edit the text, then update to rewrite its word graphics while keeping their positions. Duplicate or delete word graphics first when changing the word count.




Transcript or connection problems


Refresh from Premiere
Check that the intended timeline is active and has a transcript. Click Refresh in Generate. If the reader cannot connect, close and reopen this panel, then retry.


Use a JSON file instead
Open the JSON option in Generate and choose an exported transcript. This manual choice is remembered for the timeline until you refresh from Premiere. Captions and SRT are not required.
