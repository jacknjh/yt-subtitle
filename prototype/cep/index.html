Transcript




Automatic transcript
The active project and timeline are detected automatically. A background reader fetches the current transcript. Refresh after correcting words or timings; generation also refreshes automatic transcripts before creating graphics.


Remembered settings
Appearance, phrase grouping and transcript snapshots are saved separately for each project and timeline. Cached Premiere words are refreshed before generation. A saved manual JSON choice stays manual until you refresh from Premiere.


Choose transcript JSON file
The Generate tab's JSON fallback opens a previously exported transcript. Use it when a native transcript is unavailable or you want to supply your own data.




Style controls


Undo / Redo settings
Undo and Redo restore panel appearance and phrase grouping. Use Ctrl+Z to undo, Ctrl+Shift+Z or Ctrl+Y to redo. Each completed drag is one step. While typing, the focused field keeps its normal text undo. Histories stay separate for each timeline while this panel is open; timeline edits use Premiere's own undo history.


Pinned preview
The preview stays above the scrolling controls in a narrow panel, or beside them in a wider panel. Premiere remains the final reference for spacing and rendering.


Style and preview
Choose a phrase, play or scrub its timing, then adjust appearance. The preview is approximate and does not modify timeline graphics.


Default style and alignment
New timelines start with Times New Roman, plain word reveal and a bottom-center anchor at 50% horizontal, 90% vertical. Left, Center and Right align the visible phrase around that horizontal position. Saved styles are retained; Reset style applies the new defaults and can be undone.


Fonts and colors
Search local font faces, then choose one from the dropdown. Click a color swatch to open its picker, or type a six-digit hex color. New fonts appear after rerunning the panel installer.


Drag numeric values
Drag font size or a position value left to decrease, right to increase. Hold Shift for fine adjustments. Escape cancels the drag. Click to type; press Enter or click elsewhere when finished. Arrow keys also adjust a focused field.




Generation


Generate subtitles
Adds editable word graphics directly to an empty top video track in the current sequence. No duplicate sequence is created.


Pause / Resume
Pause finishes the current batch and retains progress. Switching timelines also pauses generation. Return to the original timeline and press Resume. The original appearance and word plan are kept. Resume requires unchanged subtitle clip positions; edit other tracks freely. One unfinished run is kept while this panel remains open.


Discard run
Forgets the unfinished run without deleting its completed graphics. Remove those graphics before generating a new run on that timeline.




Timeline edits


Set parent / Sync selected
Remembers the generated graphic under the playhead, then copies its latest appearance to the selected destinations. Press Sync again after changing the parent.


Read / Update phrase
Loads the phrase associated with a selected generated graphic. Update rewrites all its word graphics while retaining their timeline positions. Duplicate or delete word graphics first when changing the word count.
